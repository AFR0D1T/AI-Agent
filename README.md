# bank-ai-agent

Агент, который читает «грязные» финансовые документы (кредитные договоры,
KYC-досье, аудиторские записки) вместе с реестром транзакций и определяет
соблюдение финансовых ковенантов для каждого заёмщика.

Архитектура и обоснование решений — см. [PLAN.md](PLAN.md).

## Статус

Пайплайн реализован целиком (ingestion → extraction → resolution →
evaluation → assembly) и проверен: unit/integration-тестами (без сети) и
вручную на реальном датасете `agentic-bank-public` (ingestion + классификация
всех 202 документов и 1473 транзакций проходят без ошибок). Не хватает
только реального `GEMINI_API_KEY` для настоящего извлечения из документов —
без него шаг классификации/экстракции не может быть выполнен.

## Установка

```bash
python -m venv .venv
.venv\Scripts\activate  # Windows
pip install -e ".[dev]"
```

Скопируйте `.env.example` в `.env` и впишите `GEMINI_API_KEY` (Google AI
Studio, free tier).

## Запуск

```bash
python -m bank_ai_agent run --case halyk_2025
```

Результат — `artifacts/halyk_2025/submission.json`. Промежуточные LLM-ответы
кэшируются в `artifacts/halyk_2025/.cache/` — повторный запуск не тратит
квоту на уже обработанные документы.

## Тесты

```bash
pytest
ruff check src tests
```

## Структура

```
config/            # конфиги кейсов + промпты (специфика конкретной задачи)
src/bank_ai_agent/
  core/            # доменные модели, оркестратор, LLM-порт — кейс-агностично
  ingestion/        # чтение леджера/документов/шаблона ответа
  extraction/       # классификация документов + извлечение структурированных фактов
  resolution/       # связка счёт↔сценарий, версии документов, корректировка леджера
  evaluation/       # стратегии проверки ковенантов + выбор транзакции-доказательства
  assembly/         # сборка и валидация submission.json
tests/              # unit-тесты на детерминированную логику (без сети)
artifacts/          # результаты прогонов (в .gitignore)
```
